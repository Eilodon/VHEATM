# VHEATM

VHEATM is being rebuilt as a machine-validated, AI-native audit control plane.

This repository is initialized for the V17 stabilization and re-architecture program derived from the VHEATM v16.1.1 audit.

Development happens through pull requests. The first implementation milestone establishes canonical manifests, schemas, policies, executable validation, tests, and CI before migrating the legacy skill corpus.
